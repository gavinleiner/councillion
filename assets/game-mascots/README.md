# Puffer Games mascots

Original native pixel SVGs, using the existing Puffer judge's navy outline,
cream wig, white eyes and limited flat shading. No external art or fonts.
The original Party judge remains `../puffer.svg` unchanged. New icons use a
32 × 32 logical grid and transparent backgrounds.

- Counsel Clash: coral crab barrister with opposing claws.
- Final Figure: teal nautilus with a gold spiral shell.
- The Docket: blue turtle clerk reading an open law book.
- Under Oath: violet cuttlefish witness holding an oath book.

`game-mascots.js` maps each game to its mascot; the Puffer Games cove and mode
entry titles consume that mapping. Player avatars remain independently chosen.
`game-availability.js` keeps Under Oath closed to the public, including direct invites. The verified
owner has a private preview against five labelled bots.
