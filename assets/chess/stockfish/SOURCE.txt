  Build command: node build.js --single-threaded --lite -f
  Build requirements and Emscripten details are in that source README/build.js.
Lite neural network by Chris Bao (sscg13):
  https://tests.stockfishchess.org/nns?network_name=nn-61e7af4bb97d
  nn-61e7af4bb97d.nnue (served beside this file)
  https://tests.stockfishchess.org/api/nn/nn-61e7af4bb97d.nnue

Engine runs in its own Worker and is loaded only for a completed-game review.
Councillion communicates with the unmodified engine through the UCI protocol.
No Chess.com branding, artwork or proprietary review algorithm is included.
