# Formula One driver data attribution

The `sources/f1-drivers.json` factual snapshot and the derived `authored-formula-one-drivers` answer inventory adapt data from **Jolpica-F1**, which continues Ergast historical Formula One records. Retrieved October 25, 2026, from <https://api.jolpi.ca/ergast/f1/drivers/>. All nine pages were reconciled to the declared total of 881 drivers.

Jolpica-F1 data is licensed under **Creative Commons Attribution–NonCommercial–ShareAlike 4.0 International**: <https://creativecommons.org/licenses/by-nc-sa/4.0/>. Its API terms are <https://github.com/jolpica/jolpica-f1/blob/main/TERMS.md>. This attribution and the same data license apply to the factual snapshot and derived F1 answer inventory, including content-addressed compressed versions of that inventory.

Changes: retained factual driver identifiers, public racing names and documented driver codes; omitted dates of birth, biographies and images; added independently reviewed full-name/nickname aliases; assigned original editorial game points. Driver codes are retained only for provenance and do not become guessed-initial aliases in the game. This data attribution does not relicense unrelated site code or other independently licensed datasets.
