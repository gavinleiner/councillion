# Five-thousand-question expansion: development checkpoint

The requested release is unfinished. Production still has 227 admitted questions. Development has 276: the 227 baseline plus 49 new admissions. It needs 4,724 more genuinely distinct questions. Answer rows, raw entities, draft inventories and reworded recipes do not count as questions.

## Admission standard

The saved review contains 98 Yes votes and 2 No votes. Use recognizable subjects with common entry answers and a substantial valid rare tail. Do not multiply Steam tag pairs, title words, years, geographic slices or adjacent filters to fill the count. Single Steam tags remain limited to 24 in the final pool (currently 22). Each of the nine families must represent 8–15% of the finished pool; the temporary development pool is not yet balanced.

Every normal-play question requires explicit admission, an inspectable factual inventory, independently supplied familiar inputs and wrong-category boundaries. Daily and Puffer use the same admitted IDs. Every player receives the same seven Daily IDs for the shared New York date. Already-played dates must be preserved when the future release calendar is rebuilt.
