# NBA franchise roster sources

Thirty whole all-time franchise questions use 31 complete factual roster pages. The Seattle SuperSonics roster supplements the Thunder question; it does not create an additional question. There are no per-season, position, draft, opponent or paired-team recipes. The saved 98 Yes votes provide the playability model; these are new editorial admissions, not additional user votes.

The factual snapshot retains player names, identity links, named statistical columns, source retrieval dates and HTML SHA-256 values. It contains no copied article narrative, photographs or logos. Source Wikipedia tables are attributed under CC BY-SA 4.0; source page histories identify the contributors. The edited factual inventory retains that attribution.

All 508 independently supplied common-player guesses must match exactly. The inventories keep 13,408 answer identities, including the less familiar tail; six examples are not mistaken for a complete roster. Exact full names own their spelling. Documented public names and name changes are explicit; no initials are manufactured. A shared surname chooses the player with greater franchise participation without a choice dialog.

Rarity is an editorial estimate using separately supplied familiar names, franchise game/point totals where available, and tenure when those totals are absent. It is not measured player response frequency and missing game totals are not invented. Two raw Atlanta zero-stat rows conflict with independent eligibility evidence and are documented in nba-source-stat-issues.json; both actual players remain valid. Twenty-six Lakers source rows belong to a separate NBL-only table and are excluded by the stated NBA/BAA/ABA scope.

Historical names expand one franchise inventory. Charlotte history from 1988–2002 returns to Charlotte alongside the Bobcats era; New Orleans history starts in 2002. Source context and independent league/historical references support those boundaries.
